Personal research infrastructure

Encrypted backups, with recovery in mind.

Giray Research Backup is a privately operated workflow for safeguarding selected research and personal work. restic encrypts files before upload, while rclone connects the owner's computers to Google Drive.

Learn how it worksRead privacy policy

A simple recovery-focused approach

This project is intended for the operator's own devices and account. It is not offered as a hosted backup product.

01 / SCOPE

Choose

Include only selected, approved sources; exclude material that should not be backed up.

02 / PROTECT

Encrypt

Create encrypted restic snapshots locally before storing repository objects in Google Drive.

03 / RECOVER

Verify

Check integrity and perform isolated restore tests to demonstrate that snapshots can be recovered.

What this application does—and does not do

Google Drive integration

Uses Google OAuth 2.0 and the drive.file permission to access application-available Drive files for encrypted backup storage and restoration.

See the technical overview →

No public accounts

These static web pages have no sign-in form, tracking script, user uploads, or public backup service. Visitors cannot connect their Drive accounts here.
